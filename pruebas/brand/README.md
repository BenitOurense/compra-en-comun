# Market Sinc

Identidad azul y naranja aprobada por el propietario del proyecto el 30 de octubre de 2026. Dos carros enlazados; subtítulo «Listas de la compra compartidas».

Los PNG son exportaciones del icono generado para este proyecto a partir del boceto C3 aprobado. Los iconos de 192 y 512 píxeles se declaran como `any`: el sistema operativo aplica su propia presentación. El icono de Apple es de 180 píxeles.

La cabecera usa texto HTML accesible y adaptable, con una aproximación tipográfica al boceto mediante Nunito en cursiva y peso 950. El naranja del texto se oscurece para mejorar su contraste sobre crema; no se convierte el título en una imagen.

`nunito-brand.woff` es un subconjunto para el texto fijo «Market Sinc», exportado sin cambios de contornos desde Nunito-Italic[wght].ttf, del repositorio oficial google/fonts, blob `e63b7a6b390495bfe2ec827b723b51679022b61e`.
